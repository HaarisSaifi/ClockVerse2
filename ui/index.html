Technical details: File Carving, VSS & Hardware Realities

Direct drive recovery allows read-only sector scanning of USB thumb drives, camera SD cards, and secondary internal partitions (`\\.\D:`). Removable media does not execute TRIM, resulting in an expected 80–95% raw recovery rate when clusters are unoverwritten.

On internal NVMe/SATA SSDs where TRIM immediately zeroes deleted flash clusters, raw carving cannot recover permanently deleted files. ClockVerse provides two robust defenses: (1) 0 MB Instant VSS Volume Snapshots created prior to data loss, and (2) SSD Shadow Miner to retrieve pre-TRIM versions from historical Windows Shadow Storage (`Win32_ShadowCopy`).
